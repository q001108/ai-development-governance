# UI 设计来源可组合规则

视觉品牌、颜色、断点与共享组件由各项目自行绑定，规则包不提供另一套固定色值或目录。

## 视觉来源

| RuleId | 级别 | 规则 |
|---|---|---|
| `UI-001` | 必须 | 视觉样式和共享组件选择以 {{DesignSource}} 为项目来源；使用其语义约定，不在需求文档中复制易漂移的品牌参数。 |

## 操作反馈

| RuleId | 级别 | 规则 |
|---|---|---|
| `UI-002` | 应该 | 本次涉及的操作入口、反馈和可访问交互按 {{DesignSource}} 对应章节处理，验证范围仍取自当前需求的冻结定义。 |
