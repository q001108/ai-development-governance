# 后端与 API 可组合规则

本候选规则包由项目显式选择。项目的语言、目录、框架、数据库和部署平台由项目已有来源声明；这里不预设这些事实。

## API 契约来源

| RuleId | 级别 | 规则 |
|---|---|---|
| `BE-001` | 必须 | API 输入、输出、错误与兼容边界以项目声明的 {{ApiContract}} 为依据；涉及既有调用方时核对对应契约，不从模板推断新的业务要求。 |

## 数据约束来源

| RuleId | 级别 | 规则 |
|---|---|---|
| `BE-002` | 必须 | 仅当模块明确包含数据能力时，依 {{DataContract}} 核对本次改动的数据边界、事务及迁移责任；未涉及的数据库或交付平台不自动展开验证。 |
