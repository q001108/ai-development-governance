# Codex 原生插件加载与本地验证

状态：2026-10-28。在独立 CODEX_HOME、本地插件市场及合成 Git 项目中实测；不修改公司仓、个人全局插件配置或登录文件。使用当前安装的 `codex-cli 0.165.0-alpha.1.2`，结果不替代其他客户端版本和桌面界面的验证。

## 已验证的链路

1. 官方 plugin CLI 从本地市场读取根 plugin.json，将发行安装进隔离缓存；插件列表返回 installed=true、enabled=true。
2. 原生 app-server 的 skills/list 返回 `development-governance:development-governance`，路径指向安装缓存的 SKILL.md，errors 为空。插件停用后不再返回该技能，恢复启用后重新发现。
3. 显式短名称 `$development-governance` 能引导当前模型读取该技能，说明测试前入口与按需求选择发行的方式。
4. 自然语言仅要求继续已有合成需求、执行冻结计划，没有提供技能名或工具命令。模型自动读取已安装技能、需求绑定及原发行规范，然后调用项目运行器的 governance_local_tests --run。
5. 修复本轮发现的工作区运行目录问题后，V-01 单元和 V-02 集成命令均成功，服务与夹具就绪，Cleanup=COMPLETED；端口无监听，Git 状态保持干净。本地观察不是正式 QA、人工验收或门禁事实。
6. 在另一组合成 STANDARD 输入中，使用同一受限后端按项目根设置工作区，分别通过三次原生 command/exec 调用 start、test、stop。会话跨调用保持可用，V-02 成功，RepositoryUnchanged=true，最后清理完成；这验证环境桥接，不代替独立 QA 智能体及正式派发。

原生安装和发现使用的旧制品为 0.1.0-dev.1；运行目录修复为 0.1.0-dev.2；最终候选 0.1.0-dev.3 另修复会话原子写入的 Windows 长路径边界。发行内容由 release.json 和摘要固定，不原位修改旧包。当前代码的回归和最新制品摘要记录在外层执行方案及沙箱报告中。

## 本轮发现并修复的问题

新建隔离配置初次没有 Windows 执行后端，文件读取被拒绝。为测试实例显式配置官方支持的受限令牌后端后，workspace-write 与 never 审批策略保持不变，原生命令可以运行。没有扩大文件系统或审批权限。

实际 B1 首次执行仍失败：原运行数据使用系统 tempfile 私有目录；Python 3.12.7 在 Windows 创建 0700 目录后，受限令牌不能重新访问它。独立复现确认同一环境的继承 ACL 目录可写，而私有 tempfile 不可访问。另一个独立失败是 .git 私有目录受沙箱保护，诊断无法持久化。

新接入因此显式使用被 Git 忽略的 .governance/local：会话与报告保存在该目录，临时资源在独占子目录中创建并清理。Windows 继承项目 ACL，POSIX 保持 0700；不更改操作系统 ACL、不请求越过沙箱、不记录凭据。目录中存在跟踪文件或忽略项缺失时拒绝使用。已接入项目的配置保持项目维护，需要显式采用新字段；既有需求仍使用原发行。

最终加长的隔离项目还暴露了会话临时文件名过长：同目录下拼接完整请求名及第二段 UUID，路径达到 260 字符，打开临时文件时报 FileNotFoundError。原子发布改用同目录单段随机 UUID 临时名，保持独占创建与替换，减少路径长度；不改变正式请求名、会话协议或权限。新增实际文件写入回归，并用长路径项目复核 start/test/stop。

## 复现方式与结果边界

按官方文档创建本地 marketplace.json，将 source.path 指向原样校验的固定发行。CLI 的 `plugin marketplace add`、`plugin add`、`plugin list --json` 仅对试验子进程的独立 CODEX_HOME 生效。app-server 通过 initialize、initialized、skills/list 核验真实发现结果；JSON 协议从本机 CLI 生成，不猜测其他版本字段。

行为测试使用本机已配置模型服务，沿用配置中的默认模型；认证只在试验进程内经环境变量使用并从子 shell 环境中排除，不复制登录文件或将凭据写入试验配置和日志。原始工具事件、实际执行报告及失败证据保存在外层 outputs 的隔离试验目录，社区发行不包含这些样本。

该测试证明一组自然语言输入能够触发预期流程，不保证模型对任意措辞都正确选用技能。当前没有验证桌面 UI 安装交互、其他操作系统、公司真实服务及业务验收；其他 AI 工具适配仍后置。STANDARD / CONTROLLED 的独立 QA 派发继续依赖既有运行时，不能从 LEAN 成功推断全部多智能体路线已跑通。
