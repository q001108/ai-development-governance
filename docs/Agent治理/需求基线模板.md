# 需求基线模板

模板状态：`FROZEN`
模板版本：v3.0
生效日期：2026-09-16

> 适用阶段：主智能体/运行时形成需求基线并准备 G1；STANDARD / CONTROLLED 可调用总控编排器 `Invocation: REQUIREMENT_AUDIT`。
> 核心问题：用户要解决什么问题，期望获得什么业务结果？
> 本模板只形成需求事实基线，不预测技术模块，不定义技术范围、共享面、受保护面、技术风险或实现方式；这些内容在 G1 通过后由开发上下文包统一定义。

## 填写规则

- 完整保留原始需求；结构化内容不得覆盖或改写原始输入。
- 只记录有用户输入或可定位材料支持的事实。推断、歧义和缺失信息统一写入第 6 节，不得自行补齐。
- 需求类型、优先级和产物状态只沿用现有来源或治理记录的定义和值；无既有值时标记 `[需人工确认]`，不得新增枚举或状态。
- 各节与记录职责完整保留；简单需求只精练内容，不适用字段标记 `N/A`，不为填满模板扩写。
- 新产物固定使用 `需求基线.md`。目录、`RequirementId`、历史别名和冲突处理遵循[治理运行时事实协议](./治理运行时事实协议.md)；本模板和总控编排器不得自行生成或改变运行时已经分配并核验的 `RequirementId`。
