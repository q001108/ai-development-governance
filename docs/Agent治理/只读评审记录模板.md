## 记录规则

- 保留全部章节和逐轮索引，小需求同样完整；详细结论与证据引用原始 JSON，不复制正文或生成第二套事实。
- 状态、计数、迟到处理及汇合按[主流程](./多智能体协同开发治理流程.md#核心规则)和[事实协议](./治理运行时事实协议.md#持久化顺序与恢复)投影；本记录不判定路由，不阻塞角色执行，最终归档前须追平。
- 第2节可用 `python scripts/governance_tools.py render --requirement-dir <需求目录> --kind review-index` 生成区块；其他章节由原维护责任方填写，生成表格不等于完整投影。
- 历史记录继续绑定旧版本，不自动迁移。生成器只支持明确的现行输入，缺失、冲突、未脱敏或不支持版本时不生成区块，不代替协议完整校验。
